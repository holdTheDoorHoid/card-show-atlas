# Brief: follow up leads

Read `_common.md` first. Its rules always win.

Your input file lists shows that earlier agents SAW (usually in a search snippet, on Facebook, or on a
listing site we may not use) but could not confirm. Each item has a name, sometimes a URL, and a note
with what was seen. Your job: confirm each one from a page we are allowed to use, or explain why not.

For each item:
1. Never fetch the item's URL if its domain is on the never fetch list or the links only list. Read the
   note for the show name, town and date.
2. Look for the organizer's own page: try the obvious domain (for example `<showname>.com`), the venue's
   event calendar (fire hall, Elks, VFW, mall, fairground, hotel, expo center), a ticket page on an
   allowed ticketing site, a city or tourism calendar, or local news. You may use ONE WebSearch per
   item at most, and only when guessing did not work.
3. If you confirm it, write an `edition` or `series` record exactly as `_common.md` says, with the
   allowed page as evidence. If not, put it back in `leads_only` with a short note on what you tried.

Do not give up on an item after one failed guess: try the venue's own site before searching.
